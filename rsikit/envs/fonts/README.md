# Bundled Latin Modern fonts

These four unmodified OpenType fonts are from Latin Modern 2.005 (21 March 2021),
by Bogusław Jackowski and Janusz M. Nowacki, based on Donald Knuth's Computer Modern.
Source: TeX Live 2025, `texmf-dist/fonts/opentype/public/lm/`.
Upstream: https://www.gust.org.pl/projects/e-foundry/latin-modern/

- `lmroman10-regular.otf`: video titles and primary numbers.
- `lmsans10-regular.otf`: chart labels and metadata.
- `lmsans10-bold.otf`: emphasized labels and actions.
- `lmmono10-regular.otf`: identifiers.

See `GUST-FONT-LICENSE.TXT` and the accompanying upstream README/manifest.
The upstream manifest describes the complete font family; this directory distributes
only the four fonts listed above. Loading these files requires no installed TeX fonts.
