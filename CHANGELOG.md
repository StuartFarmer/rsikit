# Changelog

## 0.0.1 — release candidate (unreleased)

- Policy definitions and runtime policies, Gymnasium episode evaluation, queued
  process execution, and persistent runs.
- A common propose/evaluate/update optimizer interface with included research
  implementations and a unified experiment CLI.
- A public Guide, generated API reference, and runnable existing/custom system
  examples with offline checks.
- Apache-2.0 licensing for original project code and documentation, with separate
  third-party notices and data terms.

This is an experimental release. APIs may change. Publishing is subject to the
remaining checks in `RELEASE_CHECKLIST.md` and `maintainer/RELEASING.md`.
