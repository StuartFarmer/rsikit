# Security

rsikit is experimental software. Generated policy and strategy source is executable
Python, and static validation is not a security sandbox. Worker processes inherit
application access; the Docker launcher also mounts outputs and forwards provider
credentials. Load pickle episodes and queues only from trusted runs.

For a sensitive vulnerability, use GitHub's **Report a vulnerability** action on
the repository Security tab when available. Do not include credentials, private
data, or an exploit in a public issue. If private reporting is unavailable, open
an issue asking the maintainer for a private reporting channel without the details.

Include the rsikit version, affected entry point, and a minimal reproduction via
the private channel. No response-time commitment or maintained stable-version
support policy is established yet.
